# Book Sample Assets (Layout, CSS, Cover)

Preserved sample package from **Practical Python Data Processing**:
- `css/full-book.css`: Content chapter layout & typography stylesheet.
- `css/toc.css`: Dedicated table of contents stylesheet with hierarchical indentation (Level 2 & Level 3).
- `cover/`: Cover design files (JPG, PNG, SVG).
- `sample-book.epub`: Fully verified EPUB 3 sample with hierarchical TOC and mimetype-first packaging.
